🚀 TunnelFlow Test Application

✅ This is a test web application for tunnel testing

How to use:

  1. Create a tunnel via API: POST /api/v1/tunnels
  2. Connect your client using the tunnel token
  3. Access this page via your subdomain: http://your-subdomain.localhost

Endpoints:

  • API: http://api.localhost/docs
  • Traefik Dashboard: http://traefik.localhost:8081
