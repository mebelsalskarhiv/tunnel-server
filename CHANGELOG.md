# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

## [1.0.0] - 2025-11-22

### Добавлено
- Веб-интерфейс для управления клиентами и туннелями
- Автоматическое создание поддоменов в Traefik
- Поддержка SSL/TLS через Let's Encrypt
- Статистика подключений и трафика
- Docker Compose конфигурация

### Исправлено

#### Traefik и динамические поддомены
- Добавлен File Provider для Traefik с поддержкой динамических конфигураций
- Автоматическое создание YAML конфигураций при создании туннелей
- Автоматическое удаление конфигураций при удалении туннелей
- Настроен Let's Encrypt для автоматической выдачи SSL сертификатов
- Исправлена конфигурация для localhost (SSL отключен)

#### Архитектура проксирования
- Изменена архитектура: сервер отправляет HTTP запросы клиенту через control соединение
- Клиент получает запросы, проксирует на локальный сервис и отправляет ответы обратно
- Поддержка клиентов за NAT
- Использование base64 кодирования для передачи HTTP данных через JSON

#### Чтение данных
- Исправлено чтение больших сообщений от клиента (буферизация вместо readline)
- Улучшено чтение HTTP запросов с правильной обработкой Content-Length
- Улучшено чтение HTTP ответов с поддержкой:
  - Content-Length
  - Chunked encoding
  - Connection: close
- Увеличены таймауты для чтения ответов (10 секунд)

#### Закрытие соединений
- Исправлено преждевременное закрытие соединений
- Добавлена задержка перед закрытием соединения для корректной работы с Traefik
- Правильная обработка закрытия writer после отправки данных

#### Конфигурация
- Удалена устаревшая версия из docker-compose.yml
- Исправлены правила маршрутизации Traefik для веб-интерфейса
- Добавлена поддержка переменных окружения для домена

### Известные ограничения
- Максимальный размер ответа: 10MB
- Подход с base64 в JSON не оптимален для очень больших ответов (>10MB)
- Для больших ответов может потребоваться оптимизация протокола (потоковая передача)
