# План развития Tunnel Server v2.0: "TunnelFlow"

## 📋 Обзор проекта
**Название:** TunnelFlow  
**Цель:** Создание профессиональной платформы туннелирования с биллингом, мониторингом и удобным клиентским ПО  
**Фокус:** HTTP/HTTPS туннели через пользовательские домены и поддомены сервера (TCP удален)

### 1.2 Удаление функционала
- ❌ Удалить поддержку TCP туннелей
- ✅ Оставить только HTTP/HTTPS туннели

- JWT-токены для авторизации API
- Хэширование пользовательских токенов (SHA256 + salt)

## 2. 💰 Система биллинга

### 2.1 Тарифные планы

| План | Цена | Туннели | Трафик/мес | Домены | Поддомены | Приоритет |
|------|------|---------|------------|--------|-----------|-----------|
| **Free** | $0 | 1 | 1 GB | 0 | 1 (sub.yourservice.com) | Низкий |
| **Starter** | $5 | 3 | 20 GB | 1 | 3 | Средний |
| **Pro** | $15 | 10 | 100 GB | 5 | 10 | Высокий |
| **Business** | $50 | 50 | 500 GB | 20 | 50 | Максимальный |
| **Enterprise** | Custom | Unlimited | Unlimited | Unlimited | Unlimited | VIP |

### 2.2 Модель данных
```python
# Users
- id, email, password_hash, created_at
- current_plan, plan_expires_at
- is_active, is_blocked

# Subscriptions
- user_id, plan_id, start_date, end_date
- status (active, cancelled, expired)
- auto_renew

# Invoices
- id, user_id, amount, currency
- status (pending, paid, failed, cancelled)
- pdf_url, created_at, due_date

# Usage Logs
- user_id, tunnel_id
- bytes_in, bytes_out
- requests_count
- timestamp

# Domains
- user_id, domain_name
- type (custom, subdomain)
- ssl_enabled, ssl_status
- verified_at
```

### 2.3 Функционал биллинга
- Автоматическая генерация счетов 1-го числа месяца
- PDF-генерация счетов с логотипом и реквизитами
- Email-уведомления о счетах
- Автоматическая блокировка при просрочке >7 дней
- Апгрейд/даунгрейд плана с перерасчетом
- История платежей и счетов в ЛК

## 3. 👤 Пользовательский интерфейс (Личный кабинет)

### 3.1 Дашборд пользователя
**Визуализация ресурсов:**
- Прогресс-бары: трафик (использовано/лимит), туннели (активные/лимит)
- Графики за 24ч/7д/30д:
  - Трафик (GB) по времени
  - Requests per second (RPS)
  - Активные подключения
- Топ-5 туннелей по трафику

**Быстрые действия:**
- Создать новый туннель
- Скачать клиентский пакет
- Пополнить баланс / оплатить счет
- Добавить домен

### 3.2 Управление туннелями
- Список всех туннелей со статусом (online/offline)
- Детали туннеля: URL, трафик, uptime, последняя активность
- Кнопки: старт/стоп, перезапуск, удалить
- Логи подключений в реальном времени

### 3.3 Управление доменами
- Добавление пользовательских доменов (DNS verification)
- Автоматическая генерация поддоменов вида `tunnel123.yourservice.com`
- SSL сертификаты (Let's Encrypt авто-выдача)
- Статус верификации домена

### 3.4 Биллинг раздел
- Текущий тариф и дата списания
- История счетов (скачивание PDF)
- Оплата картой / криптой / PayPal
- Промокоды и скидки

### 3.5 Статистика и аналитика
- Детальная статистика по каждому туннелю
- Экспорт данных (CSV, JSON)
- Геолокация подключений
- User-Agent аналитика

## 4. 📦 Генератор клиентских пакетов

### 4.1 Функционал
Пользователь в ЛК выбирает туннель → "Скачать клиент":
1. Генерируется уникальный ZIP-архив
2. Внутри:
   - `tunnel_client.exe` (или бинарник под OS)
   - `config.json` (с токеном, ID туннеля, настройками)
   - `run.bat` (Windows) / `run.sh` (Linux/Mac)
   - `install_service.bat` (для автозапуска)
   - `README.txt` с инструкцией

### 4.2 Меню запуска (.bat)
```batch
@echo off
echo === TunnelFlow Client ===
echo.
echo Выберите режим запуска:
echo 1. Запустить разово
echo 2. Установить как службу (автозапуск)
echo 3. Выйти
echo.
set /p choice="Ваш выбор: "
if "%choice%"=="1" goto RUN_ONCE
if "%choice%"=="2" goto INSTALL_SERVICE
if "%choice%"=="3" exit
...
```

### 4.3 Возможности клиента
- Авто-реконнект с экспоненциальной задержкой (1s, 2s, 4s, 8s... макс 60s)
- Heartbeat каждые 30 сек для поддержания соединения
- Логирование в файл `client.log`
- Минимальные настройки через конфиг:
  ```json
  {
    "tunnel_id": "abc123",
    "token": "hashed_token_here",
    "server": "tunnel.yourservice.com",
    "port": 443,
    "local_port": 8080,
    "auto_restart": true,
    "log_level": "info"
  }
  ```
- Поддержка Windows, Linux, macOS

## 5. 📊 Админ-панель и мониторинг

- CPU/RAM использование сервера (%)

**Графики:**
- Трафик по часам/дням
- Распределение пользователей по тарифам
- Топ-10 пользователей по трафику
- География подключений (карта)

### 5.2 Управление пользователями
- Список всех пользователей с фильтрами
- Просмотр детальной статистики пользователя
- Ручная блокировка/разблокировка

- Уведомления в Telegram/Email при:

- Dashboard с историей алертов

### 5.4 Мониторинг туннелей
- Карта активных туннелей в реальном времени
- Детали по каждому туннелю:
  - Владелец, тариф
  - Трафик сейчас (KB/s)
  - Uptime
  - История переподключений

## 6. 🛠️ Технологический стек

### Backend
- **Язык:** Python 3.11+
- **Фреймворк:** FastAPI (асинхронный, быстрый)
- **База данных:** PostgreSQL 15+
- **Кэш и real-time:** Redis (pub/sub для метрик)
- **ORM:** SQLAlchemy + Alembic (миграции)
- **Аутентификация:** JWT + OAuth2
- **Задачи:** Celery + Redis (биллинг, генерация PDF)

### Frontend
- **Фреймворк:** React 18 + TypeScript
- **UI библиотека:** TailwindCSS + HeadlessUI
- **Графики:** ApexCharts или Recharts
- **Real-time:** WebSocket для обновления метрик
- **Сборка:** Vite

### Клиентское ПО
- **Язык:** Go (компактный бинарник, кроссплатформенность)
- **Библиотеки:** 
  - `gorilla/websocket` для соединений
  - `kardianos/service` для установки службы
- **Размеры:** <10 MB после компиляции

### Инфраструктура
- **Контейнеризация:** Docker + Docker Compose
- **Reverse Proxy:** Traefik v3 (SSL, роутинг)
- **SSL:** Let's Encrypt (автоматически)
- **Мониторинг:** Prometheus + Grafana (опционально)
- **Логи:** ELK Stack или Loki

## 8. 🎯 Критерии успеха

### Технические
- ⚡ Время отклика API <100ms
- 🔄 Авто-реконнект клиента <5 сек
- 📈 Поддержка 1000+ одновременных туннелей
- 🔒 99.9% uptime сервиса
- 🛡️ Отсутствие уязвимостей безопасности

### Пользовательские
- 📦 Скачивание пакета <1 клика
- 🚀 Запуск туннеля <30 сек после регистрации
- 📊 Понятные графики и статистика
- 💳 Простая оплата и прозрачные счета
- 📱 Адаптивный дизайн (mobile-friendly)

### Бизнес
- 💰 Конверсия Free → Paid >5%
- 📉 Churn rate <3% в месяц
- ⭐ NPS >50
- 📈 Средняя выручка на пользователя (ARPU) >$10
